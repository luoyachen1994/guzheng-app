## 常见问题

### 1. 上传失败
**可能原因：**
- 项目体积超过限制（2MB）
- 代码包含敏感内容
- AppID 不正确

**解决方法：**
```bash
# 检查项目大小
du -sh /Users/luoyachen/guzheng-app

# 如果太大，可以删除不必要的文件
# .git 目录不会被上传
```

### 2. 找不到上传按钮
- 确认已登录正确的 AppID
- 确认账号有上传权限
- 重启微信开发者工具

### 3. 体验版扫码打不开
- 确认微信号已添加为体验成员
- 确认已选择最新版本为体验版
- 体验版有效期90天

### 4. 后台播放不工作
- 确认 app.json 中配置了 `requiredBackgroundModes: ["audio"]`
- 体验版可能受限，正式版更稳定
- iOS 和 Android 表现可能不同
