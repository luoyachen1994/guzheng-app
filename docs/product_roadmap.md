# 古筝练习小程序 - 产品迭代计划

## 项目概述
重新设计古筝练习小程序，提供从基础练习工具到高级分析功能的完整学习体验。

## 一个月迭代计划（按优先级）

### P0 - 第一周：基础练习工具

#### 1. 节拍器功能
**目标**：为练习者提供稳定的节奏参考

**功能点**：
- 可调节速度（30-240 BPM）
- 可选节拍类型（2/4, 3/4, 4/4, 6/8等）
- 节拍音效（强拍/弱拍区分）
- 视觉指示器（闪烁或动画）
- 后台持续播放支持
- 快捷速度预设（慢板、中板、快板等）

**技术实现**：
- 使用微信小程序音频API
- 精确定时器控制
- 本地音效资源

---

#### 2. 调音器功能
**目标**：帮助学习者准确调音

**功能点**：
- 支持常用调式：
  - D调（筝最常用）
  - G调
  - C调
  - A调
  - 其他传统调式
- 实时音高检测
- 21弦音高显示（每根弦的标准音）
- 偏差指示器（过高/过低/准确）
- 参考音播放（点击播放标准音）
- 自动识别当前弦号

**技术实现**：
- 使用录音API采集音频
- FFT频谱分析检测基频
- 音高匹配算法
- 预录标准音频文件

---

### P1 - 第二周：动态曲谱系统

#### 3. 动态曲谱播放（以《梅花三弄》为例）
**目标**：提供视听同步的学习体验

**功能点**：
- 可滚动的数字简谱显示
- 音频同步高亮当前演奏位置
- 播放控制：
  - 播放/暂停
  - 进度拖拽
  - 速度调节（0.5x - 1.5x）
  - AB段循环播放
- 指法标注显示
- 小节编号定位
- 示范音频播放

**数据结构**：
```json
{
  "title": "梅花三弄",
  "tempo": 90,
  "timeSignature": "4/4",
  "key": "D",
  "sections": [
    {
      "measures": [
        {
          "notes": [
            {"pitch": "5", "duration": 0.5, "finger": "中", "timestamp": 0},
            {"pitch": "6", "duration": 0.5, "finger": "食", "timestamp": 0.5}
          ]
        }
      ]
    }
  ],
  "audioUrl": "audio/meihua_sannong.mp3"
}
```

**技术实现**：
- 自定义曲谱渲染组件
- 音频播放时间监听
- 时间戳与音符映射
- 曲谱数据格式设计

---

### P2 - 第三周：智能分析（一）

#### 4. 音准分析功能
**目标**：分析用户演奏的音准准确度

**功能点**：
- 录制用户演奏
- 与标准曲目对比分析
- 生成音准报告：
  - 整体音准得分
  - 每个音符的偏差值
  - 音准曲线图
  - 问题音符标注
- 历史记录对比
- 练习建议

**分析维度**：
- 音高偏差（cents）
- 音准稳定性
- 问题音符统计

**技术实现**：
- 后端Python音频分析（librosa）
- 音高提取与对比算法
- 数据可视化（ECharts）

---

### P3 - 第四周：智能分析（二）

#### 5. 手部动作识别与视频分析
**目标**：分析演奏姿势和手型规范性

**功能点**：
- 视频录制/上传
- 手部关键点识别
- 姿势分析：
  - 手型规范性
  - 触弦角度
  - 手指独立性
  - 动作流畅度
- 可视化标注视频
- 问题动作片段定位
- 改进建议

**分析维度**：
- 手腕高度
- 手指弯曲度
- 触弦力度一致性
- 动作连贯性

**技术实现**：
- 后端MediaPipe手部识别
- FFmpeg视频处理
- 骨骼点位分析算法
- 视频片段标注

---
