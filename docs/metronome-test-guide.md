## 常见问题排查

### 1. 页面打不开
- 检查 app.json 中是否正确添加了 pages/metronome/metronome
- 检查页面文件是否都存在（.js .json .wxml .wxss）

### 2. 编译报错
- 查看控制台具体错误信息
- 检查 JSON 文件语法
- 检查 requiredBackgroundModes 配置

### 3. 节拍不准
- 在模拟器中可能不准确，真机测试更准
- 长时间运行检查是否有累积误差

### 4. 动画卡顿
- 检查开发者工具性能
- 真机测试效果更好
