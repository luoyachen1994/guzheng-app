# 音效文件说明

节拍器需要以下音效文件：

## 1. 木鱼音效 (wooden/)
- `strong.mp3` - 强拍音效（低沉的"咚"声）
- `weak.mp3` - 弱拍音效（清脆的"哒"声）

## 2. 古筝音效 (guzheng/)
- `strong.mp3` - 强拍音效（古筝中音5，音量较大）
- `weak.mp3` - 弱拍音效（古筝中音5，音量较小）

## 3. 电子音效 (electronic/)
- `strong.mp3` - 强拍音效（高频提示音）
- `weak.mp3` - 弱拍音效（低频提示音）

## 音频规格要求
- 格式：MP3
- 采样率：44.1kHz
- 时长：<0.5秒
- 文件大小：<50KB/个
- 音量：适中，不刺耳

## 获取音效的方式
1. 自行录制
2. 使用免费音效库（如freesound.org）
3. 使用音频编辑软件合成（如Audacity）

## 临时解决方案
在音效文件未准备好之前，代码中已实现fallback机制：
- 使用 wx.showToast 显示"强"/"弱"文字提示
- 或使用系统提示音代替
